# 张伟 · 休闲游戏制作人作品集

## 本地打开

直接打开 `index.html` 即可浏览。

PDF 版打开 `张伟-休闲游戏制作人-作品集.pdf`。

页式源文件为 `portfolio-deck.html`，可在浏览器打印为 16:9 PDF。

如需启动本地服务器：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。
