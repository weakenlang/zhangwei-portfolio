# 张伟 · 游戏制作人作品集 2026

## 交付内容

- `index.html`：作品集首页，包含个人定位、三份主案例索引、工作方法与经历。
- `cases/`：CaptainCapy、关关难不住、合合合英雄三份完整案例。
- `assets/`：经过统一尺寸与 WebP 压缩的项目截图。
- `favicon.svg`：与页面品牌色一致的站点图标。
- `styles.css`、`app.js`：响应式样式、移动端导航与邮箱复制交互。

## 本地查看

直接打开 `index.html` 即可浏览。需要本地服务器时，可在本目录运行：

```powershell
python -m http.server 4173
```

然后访问 `http://localhost:4173/`。

## 内容口径

- 三份主案例按“问题、约束、判断、动作、交付、结果、复盘”展开。
- 首页定位强调把有潜力的方向推进成可验证、可交付的产品。
- CaptainCapy 只声明推进到可测试阶段，不把“可以首测”写成“验证成功”。
- CaptainCapy 的 300 万元是批准预算；约 100 万元是形成首测包输出阶段的累计消耗，两者不混用。
- 关关难不住区分团队阶段性结果与我的负责范围。
- 合合合英雄使用 AppMagic 统计周期内的相对变化，不表达为绝对收入。
- 未验证项与结果边界只在案例证据区说明，不承担首页核心定位。
- 页面不展示内部数据表、同事信息或未脱敏过程文件。

## 部署

将整个 `portfolio-2026` 目录上传至 GitHub Pages、Netlify 或其他静态网站服务即可。页面没有外部字体、接口或构建依赖。

## 更新建议

后续新增案例时，优先保持三份主案例的深度，不继续无限增加首页项目数量。更多 Demo 可作为面试附录或单独案例页补充。
